# Identité SANDBOX

`logo.png` est le logo officiel commun aux outils. Les dossiers `youtube/`, `obs/` et `social/` conservent les consignes graphiques et les sources SVG disponibles.

Les PNG de bannières, avatars, couvertures et miniatures sont des exports locaux. Ils restent sur le poste qui les produit et ne sont plus suivis dans Git. Les anciens exports de ce poste sont encore présents dans ces dossiers ignorés ; un nouveau clone ne les contient pas.

Les miniatures d'épisode de la factory sont générées sous `.local/factory/`. Leurs revues restent liées aux empreintes des fichiers locaux, selon la [procédure des miniatures](../../docs/factory/miniatures.md).
