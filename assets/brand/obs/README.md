# Plateau Sandbox pour OBS

Fond de studio sans personnages, chaises, microphones ni texte. Le décor reprend le plateau de l'accueil : bois, éclairage ambre et bleu, petite télévision, porte et miniature automobile.

- sandbox-plateau-obs-1920x1080-v1.png : export opaque 16:9 pour une scène OBS en 1920 x 1080.
- sandbox-plateau-obs-source-v1.png : image native générée, 1672 x 941 pixels, conservée sans modification.

Ajouter l'export comme source Image dans OBS, sous les sources des caméras. Le fichier est un fond complet, sans zones transparentes.

Production par l'outil intégré image_gen.imagegen à partir de apps/site/public/images/home/studio-easter-eggs-v3.webp. La référence et la génération native sont préservées. L'export est redimensionné à 1920 x 1080 ; il ne provient pas d'une génération native Full HD. Aucun fichier du site n'est remplacé.

Le prompt exact est enregistré dans generation-v1.json.
