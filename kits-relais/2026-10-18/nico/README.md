# Kit de relais de Nico

Angle proposé : agents et développement. Tous les textes sont facultatifs et modifiables. Aucune date de publication imposée.

| Usage                         | Fichier                                                          |
| ----------------------------- | ---------------------------------------------------------------- |
| LinkedIn, épisodes 1 et 2     | [Textes](linkedin.md)                                            |
| X, trois propositions courtes | [Textes](x.md)                                                   |
| GitHub                        | [Mode d'emploi](github.md) et [bloc de profil](github-profil.md) |
| Image horizontale             | [Carte 1200 x 675](assets/carte-paysage.png)                     |
| Image carrée                  | [Carte 1080 x 1080](assets/carte-carree.png)                     |
| Épisode 1                     | [Extrait vertical existant](assets/extrait-episode-1.mp4)        |

| Accessibilité                 | [Texte alternatif](assets/texte-alternatif.txt)                  |

Choisir un texte, télécharger une seule pièce jointe, vérifier le lien et publier quand vous le souhaitez. Les vidéos autonomes plus longues sont dans [le dossier partagé](https://github.com/Sandbox-podcast/sandbox-podcast-resources/tree/main/kits-relais/2026-10-18/videos/README.md).

La présentation de Sillage est attribuée à Nicolas dans le chapitrage de l'épisode 1. Les formulations du kit restent des propositions à adapter, pas des citations de l'émission.

Les brouillons parlent à la première personne pour être copiables. Ils ne prétendent pas reproduire vos propos mot pour mot.

## Associer le bon extrait

`extrait-episode-1.mp4` porte sur "Choisir son harnais". Son passage source est https://youtu.be/GgSiPkADCz4?t=2669. `extrait.mp4` vient de l'épisode 2 ; ses bornes et son lien sont dans `assets/extrait.json`. Choisir la vidéo qui correspond au texte. Pour une présentation générale ou un sujet différent, utiliser la carte plutôt qu'un extrait sans rapport.
