# GitHub de Loïc

Compte documenté : https://github.com/azerothl

## Profil personnel

Copier le contenu de `github-profil.md` dans le README existant du dépôt de profil `azerothl/azerothl`. Conserver les autres sections de votre présentation. S'il n'existe pas, vous pouvez créer ce dépôt vous-même quand vous souhaitez utiliser le kit.

L'image pointe vers la branche `main` du dépôt SANDBOX : elle fonctionnera après intégration de la PR. Avant intégration, utiliser simplement le lien texte vers YouTube ou télécharger la carte.

## Dépôt lié à un sujet

Si un de vos projets traite du sujet abordé, ajouter un lien vers le passage pertinent dans sa documentation. Ne pas modifier les README sans rapport avec la vidéo. Le fichier `github-profil.md` fournit les deux liens déjà horodatés.

Aucun compte personnel ni dépôt de profil n'a été modifié par ce kit.
