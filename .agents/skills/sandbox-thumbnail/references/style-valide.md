# Essais couleur validés le 4 novembre 2026

Les trois miniatures représentent Lou, Nicolas et Loïc, de taille comparable, avec une accroche explicite au-dessus. Les essais ont été générés avec ImageGen puis inspectés à 320 et 160 pixels. L'utilisateur a validé cette direction pour le skill ; aucune publication ni performance YouTube n'est attestée.

| Épisode | Accroche | Couleurs | Ordre de gauche à droite et vêtements |
|---|---|---|---|
| 1 — modèles et harnais | IA : le modèle ne suffit pas | Crème, texte bleu nuit, IA bleu pétrole | Lou pull ardoise ; Nicolas t-shirt bordeaux ; Loïc surchemise olive |
| 2 — IA pour les métiers | L'IA pour ton commerce | Bleu glacier, texte bleu nuit, commerce bleu pétrole | Loïc polo rouille ; Lou chemise bleu clair ; Nicolas pull écru |
| 3 — code IA en production | Du code IA en production ? | Bleu nuit, texte blanc cassé, code IA cyan | Lou surchemise grise ; Nicolas pull terracotta ; Loïc chemise denim |

La palette vient du kit YouTube Sandbox : bleu nuit #071A29 et cyan #1CB5ED. Le bleu pétrole #08799E est une adaptation de contraste sur fond clair ; le bleu glacier #DDEFF4 et le crème sont des fonds d'essai validés. Le petit triangle cyan rappelle l'icône. Ni effets lumineux, ni logos d'outils, ni décor spatial.

Sources de charte : [DD-0011](https://github.com/Sandbox-podcast/sandbox-podcast-site/blob/main/docs/design-decisions/DD-0011-identite-youtube-sandbox.md) et [kit YouTube](https://github.com/Sandbox-podcast/sandbox-podcast-resources/tree/main/assets/brand/youtube).
