# Projets éditables

- `videos/` conserve les sources des jingles et du générique Remotion.
- `experiments/` conserve les sources des expériences de présentation.
- `relay-kits/` conserve les scripts et compositions réutilisables des anciens kits.

Les sources sont partagées. Les médias, captures, mixes, miniatures et rendus restent sur le poste de travail, dans les dossiers ignorés du projet ou sous `.local/`. Les README des projets décrivent leurs entrées historiques ; ils ne garantissent pas leur présence sur un nouveau clone.

Pour un nouvel épisode, partir de la [factory](../docs/factory/README.md). Le [guide d'organisation](../docs/organisation.md) donne les emplacements locaux et la correspondance avec les anciens dossiers.
