# Ressources de production SANDBOX

Ce dépôt regroupe les sources réutilisables, projets éditables, outils et procédures de production du podcast SANDBOX. La factory s’exécute sur le poste de la personne qui prépare l’épisode.

## Trouver les sources et les sorties

Les projets éditables sont sous projects/ et les moteurs sous tools/. Les médias de travail et les exports produits par la factory restent dans l’espace local, dont l’emplacement par défaut est .local/factory/. Les décisions et le code du site média se trouvent dans le dépôt du site.
